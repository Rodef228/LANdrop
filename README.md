## Запуск
```bash
go run ./cmd/node/main.go
```
### Флаги:
* `-name` - имя пользователя (если не указывать, то генерится само)
* `-port` - порт (по умолчанию: 8080)
* `-storage` - путь до папки, сохранение

## Команды:
* `/announce [путь до файла] [id файла]` - анонсировать файл (id можно не укзывать, генерится сам)
* `/download [id файла]` - скачать файл по id
